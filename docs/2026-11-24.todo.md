## 2. "지금 시각을 정한다"의 뜻

- 실제 화면(`page.tsx`)은 **선택지 없이 항상 진짜 지금 시각**. "정한다"는 여기서 한 번 만들어 아래로 똑같이 넘긴다는 뜻이다. 함수마다 따로 `new Date()`를 부르면 서로 다른 순간을 볼 수 있다.
- **특정 시각으로 돌려 보는 건 테스트에서** 한다. 규칙 함수가 시각을 인자로 받으니까 가능하다.

| 어디서 | 넘기는 시각 | 목적 |
|---|---|---|
| `page.tsx` | `new Date()` | 사용자에게 지금 상태를 보여줌 |
| 테스트 | `kst("08:00")`, `kst("23:59:30")` | 아침·자정·마감 순간을 기다리지 않고 확인 |

- 함수 안에서 `new Date()`를 불렀다면 "아침 8시 화면"을 보려고 진짜 8시까지 기다려야 했다. Vue로 치면 컴포넌트가 직접 fetch하지 않고 props로 받게 만들어 테스트에서 아무 값이나 넣는 것과 같은 원리.

## 4. 어디까지가 서버 컴포넌트인가 (`app/page.tsx` 오늘 마감 부분)

```tsx
<section>                                    서버
  <SectionHeader />                          서버
  {closing.length === 0 ? (                  서버 (분기 판단)
    <EmptyNotice>{formatKstTime(…)}</…>      서버 (시각 계산)
  ) : (
    <Carousel>                               ★ 클라이언트
      <CarouselContent>                      ★ 클라이언트
        {closing.map((deal) => (             서버 (반복)
          <CarouselItem>                     ★ 클라이언트
            <DealCard deal={deal} now={now}/> 서버 ← 클라이언트 안에 있어도 서버
          </CarouselItem>
        ))}
      </CarouselContent>
      <CarouselPrevious /> <CarouselNext />  ★ 클라이언트
    </Carousel>
  )}
</section>
```

- `"use client"`는 `components/ui/carousel.tsx`에만 있다.
- 서버/클라이언트는 "어디 안에 들어 있나"가 아니라 **"어느 파일이 import해서 그리나"**로 정해진다. `DealCard`는 `page.tsx`(서버)가 그리고, `CarouselItem`은 그 결과를 children으로 받아 자리에 놓기만 한다 (Vue의 slot과 같음).
- `carousel.tsx`가 `DealCard`를 직접 import했다면 `DealCard`도 클라이언트가 되어 JS가 브라우저로 갔을 것이다.

| 서버가 하는 일 | 브라우저가 하는 일 |
|---|---|
| 보여줄 딜 고르기, 빈 상태 판단, 마감 문구 계산, 카드 HTML 만들기 | 카드 줄 밀기, 화살표 이동, 화살표 켜고 끄기 |

## 5. 서버가 넘긴 props는 클라이언트 컴포넌트로 언제 가나

**첫 응답 한 번에 같이 간다.** 추가 요청은 없다.

```
① 요청 → ② 서버 렌더링 (클라이언트 컴포넌트 자리에는 "props 메모"만 남김)
→ ③ 응답: HTML + RSC Payload(<script> 안의 props 메모)
→ ④ HTML이 먼저 보임 (아직 안 움직임)
→ ⑤ 클라이언트 JS만 다운로드
→ ⑥ hydration: RSC Payload에서 props를 꺼내 이벤트 연결 → 움직임
```

- 증거: 홈 HTML에서 `오늘 마감 전체보기`가 2번 나왔다 (본문 1번 + RSC Payload 1번). 페이지 소스에서 `self.__next_f.push`로 찾아볼 수 있다.
- props는 데이터로 바뀌어 네트워크를 건너가므로 **넘길 수 있는 값이 정해져 있다**: 문자열·숫자·배열·객체·서버가 그린 JSX(children)는 되고, **일반 함수는 안 된다**. 그래서 자동 넘김 함수(`() => api?.scrollNext()`)는 클라이언트 파일 안에서 만든다.
- 캐러셀을 넘길 때는 서버 요청 없음(모든 장이 ③에서 이미 옴). `<Link>`로 이동하면 HTML 없이 RSC Payload만 새로 받는다.
- Nuxt SSR의 HTML + `__NUXT__` 상태 → hydration과 거의 같다. 차이는 서버 컴포넌트의 코드는 브라우저로 아예 안 간다는 것 (`DealCard`는 결과만 감).
- 더 읽기: `docs/nextjs-rendering-guide.md` 3번(Hydration, RSC Payload), 3-1번(children vs import).
